# Calcule Nutri 🥗💻

## 📌 Sobre o Projeto
**Calcule Nutri** é uma ferramenta web interativa para cálculos nutricionais, auxiliando nutricionistas e profissionais da saúde na avaliação de parâmetros metabólicos e antropométricos. O projeto integra diversas calculadoras em uma única plataforma intuitiva e responsiva.

## 🚀 Funcionalidades
- **Cálculo da Taxa Metabólica Basal (TMB)**
- **Cálculo do Gasto Energético Total (GET)**
- **Cálculo de Superávit e Déficit Calórico**
- **Cálculo do Índice de Massa Corporal (IMC)**
- **Cálculo de Índices Bioquímicos**
  - HOMA-IR *(Matthews et al., 1985)*
  - Relação TG/HDL
  - Relação LDL/HDL
